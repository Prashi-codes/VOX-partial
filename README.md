# VOX Assistant 🎙️

VOX is an Android voice assistant built using Kotlin and Jetpack Compose. It can listen to voice commands, speak responses, provide weather updates based on location, read Kannada news, and open installed applications.

## ✨ Features

- 🎤 Voice recognition using Android SpeechRecognizer
- 🔊 Text-to-Speech responses
- 🌦️ Real-time weather updates using current location
- 📰 Kannada news updates
- 📱 Open apps using voice commands
- ⏰ Tell current time and date
- 🎨 Modern Jetpack Compose UI
- 🌍 Location-based services

## 🛠️ Built With

- **Kotlin**
- **Jetpack Compose**
- **Android SpeechRecognizer API**
- **Android TextToSpeech API**
- **Google Play Services Location**
- **OpenWeatherMap API**
- **NewsData.io API**

## 🚀 Voice Commands

| Command | Action |
|----------|--------|
| "Hello" | Greets the user |
| "Who are you" | Introduces VOX |
| "What is the time" | Tells current time |
| "What is today's date" | Tells current date |
| "Open YouTube" | Opens YouTube |
| "Open WhatsApp" | Opens WhatsApp |
| "Open Chrome" | Opens Google Chrome |
| "Weather" | Gives current weather |
| "Today's News" | Reads Kannada news |
