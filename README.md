# 🤖 VOX - AI Voice Assistant

---

# 🚀 Overview

VOX is an intelligent Android AI assistant built completely in **Kotlin** using **Jetpack Compose**.

Inspired by **JARVIS**, VOX combines voice recognition, artificial intelligence, reminders, weather, news, and much more into one futuristic assistant.

Unlike traditional assistants, VOX is being designed as a complete AI ecosystem where multiple intelligent modules work together.
